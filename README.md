# Curso de Trading — Índices Sintéticos y Forex

Material del curso (diapositivas y recursos).

## Diapositivas — Clase 1: Introducción al Trading

Hay dos versiones:

- ⭐ **Versión PREMIUM (recomendada):** `diapositivas/Clase_01_PREMIUM.pptx`
  - 22 diapositivas con diseño profesional: degradados, motivo de velas japonesas,
    tarjetas, diapositivas separadoras de sección y numeración.
  - Vistas previas: carpeta `diapositivas/previews_premium/`
- **Versión básica:** `diapositivas/Clase_01_Introduccion_al_Trading.pptx`
  - 17 diapositivas, diseño simple. Vistas previas: `diapositivas/previews/`

Ambas incluyen **notas del orador** (el libreto hablado) en cada diapositiva.

### Cómo descargar el PowerPoint
1. Entra a la carpeta `diapositivas/`.
2. Haz clic en el archivo `.pptx` que quieras.
3. Pulsa el botón **"Download raw file"** (icono de descarga, arriba a la derecha).
4. Ábrelo con PowerPoint o Google Slides para editarlo.
